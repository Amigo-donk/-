# 孔大山 · AIGC 视频与设计作品集

作品包含极创吹风机漫剧广告、Nike 跑鞋宣传片、拓陆者登山包广告、卡萨帝 CN7PLUS 广告漫剧、国内外真人漫剧图文案例及“莲韵新生”包装设计。

## 免费上线：GitHub Pages

在本仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 main，目录选择 / (root)，点击 Save。
发布完成后以 Pages 页面显示的地址为准。根目录首页会跳转到 portfolio/。

## 本地查看

在本仓库执行 `python3 -m http.server 8000`，使用浏览器访问本地服务。
网站为纯静态文件，无需安装依赖或执行构建。
